# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [Unreleased]

### Added
- Initial project structure
- Core modules: config, provider, chain, contracts, types, exceptions
- Token operations: ERC20, ERC721, ERC1155, approvals, balances
- Wallet management: hot wallet, Safe wallet, transaction builder
- DEX integrations: Uniswap V2/V3/V4, SushiSwap, Curve, PancakeSwap
- Lending protocols: Aave V2/V3, Compound V2/V3, Morpho
- Price oracles: Chainlink, Pyth, Uniswap TWAP, aggregator
- Analytics: APY/APR calculations, impermanent loss, PnL, gas
- Utilities: ABI loading, encoding, retry, multicall, events
- Comprehensive test suite
- Documentation with MkDocs
- Example scripts
- GitHub Actions for CI/CD
